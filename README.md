## UI / UX

Versi terbaru menggunakan tampilan course hub yang lebih modern dan mudah dipindai:
- dark hero + colorful Gen-Z accents;
- weekly class board;
- semester journey berbasis fase;
- toggle Journey / Compact schedule;
- search untuk schedule dan material;
- material cards seperti playlist;
- task tracker dan grading map;
- responsive untuk mobile.
