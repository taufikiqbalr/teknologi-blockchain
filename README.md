# Teknologi Blockchain — Course Hub

Portal perkuliahan Teknologi Blockchain ITTS untuk kelas TI229 dan IF235, Semester Ganjil 2026/2027.

Website ini dirancang sebagai course hub untuk jadwal kelas, rencana materi 16 pertemuan, materi mingguan, tugas/kuis, komponen penilaian, dan referensi.

## Kelas

- TI229 — Teknologi Blockchain (Eksekutif): Senin, 19:00–21:30 WIB — Zoom
- IF235 — Teknologi Blockchain (Reguler): Selasa, 09:45–12:00 WIB — Ruang Kelas 1
- IF235 — Teknologi Blockchain (Eksekutif): Jumat, 19:00–20:20 WIB — Zoom

## Deploy

Repository ini dibuat sebagai static site tanpa dependency build sehingga dapat langsung di-import ke Vercel dari GitHub.
